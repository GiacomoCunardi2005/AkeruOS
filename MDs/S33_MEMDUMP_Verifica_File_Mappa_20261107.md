# Verifica host dei file multiregione

Il 7 novembre 2026 è stato aggiunto `Python_Trace_Scripts/s33_check_memdump_regions.py`, verificatore in sola lettura dei file previsti dal prototipo v8. Richiede una mappa fornita separatamente come array JSON di oggetti con `address` e `length` interi decimali, e una directory di copie dei file. Controlla mappa ordinata/non sovrapposta, limite MMIO, nomi per indirizzo, lunghezze comprensive del prefisso di 256 byte, file mancanti, inattesi o collegamenti simbolici; calcola SHA-256 in streaming. Codice uscita 0 indica solo corrispondenza alla mappa dichiarata, 1 indica file mancanti, inattesi o lunghezza errata, 2 errore di input.

I test `python3 -m unittest discover -s Python_Trace_Scripts -p test_s33_check_memdump_regions.py -v` passano. Inoltre, estraendo temporaneamente i file dalle immagini FAT sintetiche del [caso completo](../Risultati/Runtime_Kernel/MEMDUMP_V8_Fixture_Map/20261107T130434894803Z/evidence.json) e [caso pieno](../Risultati/Runtime_Kernel/MEMDUMP_V8_Map_Errors/20261107T130419918161Z/evidence.json), il primo corrisponde alla mappa di prova, il secondo segnala la seconda regione corta e la terza mancante. Nessuna SD è stata modificata.

La verifica non accerta contenuti attesi, origine, chiusura, persistenza, simultaneità o completezza della RAM fisica: anche file vecchi della lunghezza corretta possono passare. La mappa deve essere fornita e conservata indipendentemente; il firmware v8 non la salva. La [foto della scheda S33 nella guida iFixit](https://www.ifixit.com/Guide/Nikon+Coolpix+S33+Motherboard+Replacement/56907) non rende leggibile una sigla di RAM utile a stabilire la mappa. Obiettivo di acquisizione completa aperto; **NON_INSTALLARE**.
