# Reference documents

This collection points to documents used during the research. A document being
available online does not by itself grant permission to republish it. External
links are maintained by their respective publishers or hosts and may change.

## ARC architecture

- [ARCompact Instruction Set Architecture Programmer's Reference, 5115-029](https://docs.alexrp.com/arc/arcompact.pdf)
  — ARC International, 2008; third-party mirror, not an official publisher site.
  The document identifies itself as publicly available but its notice restricts
  reproduction without written permission, so a copy is not included here.
  It covers the ISA, ABI and auxiliary registers; it is not the missing ARCv1
  DSP options specification.
- Three ARC700 reference documents covering external interfaces, memory
  components and memory management were consulted locally. The copies bear
  confidentiality notices; they are not redistributed or linked here. Ask the
  rights holder about authorized access.

## Camera, storage and USB

- [Nikon COOLPIX S33 Reference Manual](https://downloadcenter.nikonimglib.com/en/products/208/COOLPIX_S33.html)
  — Nikon's official download page and terms.
- [USB Mass Storage Bulk-Only Transport 1.0](https://www.usb.org/sites/default/files/usbmassbulk_10.pdf)
  — official USB-IF PDF; the licence in the document limits copying and
  distribution to internal use.
- [Toshiba TC58NVG1S3ETA00 NAND data sheet](https://media.digikey.com/pdf/data%20sheets/toshiba%20pdfs/tc58nvg1s3eta00.pdf)
  — Digi-Key mirror.
- [Kioxia TC58BVG0S3HTA00 BENAND data sheet](https://xonstorage.z8.web.core.windows.net/pdf/kioxiaamerica_tc58bvg0s3hta00_apr22_xonlink.pdf)
  — X-ON mirror.
- [Toshiba/Kioxia TC58NVG1S3H brochure](https://xonstorage.z8.web.core.windows.net/pdf/kioxiaamerica_tc58nvg1s3htai0_xondec20_20_link.pdf)
  — X-ON mirror; this is a brochure, not a full data sheet.

These memory documents describe candidate families, not confirmed S33 chip
identifications. Other local copies carry confidentiality notices or have
unclear redistribution terms and are not included. The combined searchable PDF
is also omitted because it contains copies of the same restricted documents.
